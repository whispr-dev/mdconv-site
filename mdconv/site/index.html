A little tool. A private workspace.

Markdown rendering and text comparisons run locally in a browser worker. Pasted and opened text is never uploaded by this application. Drafts live in tab memory only: reloading or closing the tab loses them. Download anything you want to keep.

Markdown uses GitHub Flavored Markdown, with sanitised HTML. Embedded images become descriptive text, and active content, styles, forms and media are removed. Preview links open only when you click them. This is a previewer, not a code runner. Code blocks are displayed as plain text.

Diff mode compares case and whitespace, normalises CRLF/CR line endings to LF, and marks a missing final newline. Changed lines are aligned in order; that alignment does not claim to identify moved blocks. Each input is limited to 250,000 characters and 5,000 lines; complex comparisons may ask you to use a smaller selection.

No application cookies, analytics, local storage or advertising trackers. SkeleTrace links are ordinary links. Hosting and proxy providers still process the connection data needed to deliver the page; enabled Cloudflare security features may set their own cookies.
